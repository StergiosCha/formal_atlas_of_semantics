# PTQ from the primary source

This branch reconstructs Montague (1973), *The Proper Treatment of
Quantification in Ordinary English*, from the consulted reprint and its
editorial corrections. It is separate from the frozen proof-theory and
legacy-preservation workbenches. Start with [the source map and completion
ledger](SOURCE_MAP.md). The [source-discrepancy proof](SOURCE_DISCREPANCY.md)
explains why the blanket claim that every printed example follows from the
literal rules is false. The [technical report](FINISHING_REPORT.md) gives the
implementation and review context.

Current checkpoint: 27 modules, 443 proved statements, 49 rejected negative
fixtures. All 26 listed analysis/formula pairs and the editor's exact T3
fresh-name procedure now have correspondence proofs. Two printed examples
are proved ungenerated by *every* analysis tree under the literal rules.
This is a checked counterexample to source coverage, not a full-PTQ adequacy
certificate or a claim of exhaustive classification for the other sentences.

A [separately labelled surface amendment](SURFACE_AMENDMENT.md) now restores
both strings. It checks all 20 registered strings and their 26 analysis/formula
pairs without changing the compiler or semantics. General proofs establish
that the original policy is unchanged and that the amendment only changes
verb forms, preserving token identity/order and success/failure for every tree.

The [reading-classification audit](READING_CLASSIFICATION.md) proves the old
two-candidate belief entry incomplete and adds a third, pairwise-distinct
reading. The revised registry has 27 certified analysis/formula pairs for
the same 20 strings. All 2,073 trees discovered by inverse search are now
classified into that registry with Coq proofs valid in every admissible model.
Redundant bare-pronoun wrappers now have an all-tree, meaning-preserving
normalization proof. Local F10 inversion, capture-safe binder freshening and
the decreasing inverse-body measure are also proved. The whole-search
coverage bridge is still missing; no exhaustive classification is claimed.

The current pipeline is:

```text
typed English analysis tree
    | total T1-T17 translation
    v
typed intensional-logic expression
    | Boolean interpretation at a world/time index
    v
truth value
```

An independently defined interpretation of the tree gives the same result,
by `translation_interpretation`. Named IL has its own evaluator, with a
general meaning-preservation theorem into intrinsic syntax. The actual
object-language formulas for all nine meaning-postulate families are proved
to characterize precisely the semantic conditions on models.
The supplied model satisfies them and demonstrates the temperature
counterargument and five nonreferential readings.
This is no longer merely a preservation result for the old, source-divergent
evaluator. F0-F15 surface operations and a checked example catalogue are now
implemented. This is not yet a full surface-English or reading-exhaustiveness
result: literal S4/S12 cannot generate two printed coordination examples.
Interpreting absent-occurrence substitution as a no-op also has a checked
truth-changing counterexample.

## Reproduce

Requires Coq 8.20.1 and Python 3. From the repository root:

```sh
python3 deep/montague_ptq/check.py --check
python3 -m unittest discover -s deep/montague_ptq -p 'test_*.py'
python3 deep/montague_ptq/check_reading_exploration.py --check-report deep/montague_ptq/reading_exploration.json
```

The checker compiles temporary copies, kernel-rechecks the modules, audits
every parsed definition and theorem, checks general theorem signatures,
rejects deliberately invalid fixtures and compares the result with
`verification.json`. Neither the source PDF nor a provider key is needed.
Use `--record` only after reviewing intentional changes to the checkpoint.

An ordinary local build is also available via `_CoqProject`; its namespace
is `MontaguePTQ`, not the namespaces of the old workbenches.

## What the assumptions mean

The model explicitly supplies Boolean reflection of classical propositions
and function extensionality. `ClassicalDecision` and `FunExt` suffice to
construct the supplied admissible example. These are not global imported
axioms, but they are genuine premises. The semantics is full internal Coq
function-space semantics, not a theorem about an external set universe.

The listed formula reductions and exact editorial T3 correspondence are
completed. A positive full-paper adequacy claim cannot be proved for the
unchanged literal surface rules: the generation component is refuted.
The explicit amended policy now has registered coverage and unchanged-tree
formula certificates. These are not all-analysis reading-exhaustiveness
proofs. Classification of every reading is not certified here. No human
source-review
endorsement, deployment or publication is implied by the checks.
