## Additional source reading

Cooper 2023 section 7.4 pp.312-313, especially (69): a negative witness belongs
to a type that precludes the positive type across possibilities. This is not
defined as mere non-membership in a single extension. Section 2.4 p.62 also
distinguishes negative attitudes/speech events; those are outside our fragment.

Ranta sections 6.1-6.2 pp.125-127: progressive conjunction supports the
content comparison, but the book prefers a context of assertions for texts.
The Sigma representations in this checkout reify instances of that context;
they do not replace Ranta's assertion/proposition distinction at source level.

Bekki & Mineshima 2017 sections 3.4-3.7 pp.28-31 and 4.2 pp.32-33:
the type-checking/felicity condition, resolution as a typed equation (Def.5),
projection proof (41), accommodation, accessibility, and presupposition
formation under negation. Bekki 2014 is still unavailable. This is not a
claim to have implemented the checker cited from Bekki & Sato 2015.

## Implemented resolution

`DTS_Resolution.v` has object terms for projections and indexed holes, a
typing judgement, typed resolution equations, and a consistent substitution.
The entity-projection search has an iff specification against telescope
shape. Arbitrary dependent evidence types remain in the semantic telescope;
proof fields are skipped during entity search, not erased from the source
context. Explicit inverse flatten/unflatten maps and a projection-adequacy
theorem connect the mini-discourse context to that representation.

An executable resolver selects the first candidate for each declared hole.
Typing preservation and totality on nonempty projection contexts are proved.
This deterministic policy is added engineering, not a source salience claim.
Search retains both alternatives in a two-entity context; the example verifies
that they can denote different individuals. Empty and undeclared-hole cases
return no result. Negation retains the same typing obligations.

Scope limits: only entity-target pronouns, projection-only candidates, finite
telescope shape, explicitly declared holes. No general dependent type inference,
proof search over arbitrary terms, CCG interface, accommodation, background
knowledge, gender/number filtering or dependent definite-description targets.
Empty projection search does NOT prove global infelicity. The local-context
test is about the supplied context shape, not a theorem about every possible
term in full DTS.

## Four shared constructions

`Shared_Examples.v` uses explicitly induced noun types at a fixed TTR model.
It compares constructions, not the full theories or their lexical analyses.

| Construction | What is proved; important boundary |
|---|---|
| John is a student | Fixed-model membership agrees with MTT's simplified image proposition and the induced Ranta/DTS evidence. No prior Student typing of John is assumed. |
| John is not a student | Constructive negative image/evidence translations for MTT/Ranta/DTS. Cooper-style negative witnesses imply exclusion; no converse or identification with fixed-model non-membership is asserted. |
| If John is a student, he studies | Image/evidence translations preserve the conditional. TTR's side uses a fixed-model metalanguage condition, not a newly implemented object-language function type. |
| A man entered. He whistled. | Strong Sigma works in both MTT and Ranta; explicit maps connect the DTS predicate context, and the individual plus event witnesses produce a well-typed TTR record. The pronoun's typed equation is obtained from the projection search. |

The general Type-valued Sigma constructor is now explicit as
`MTT.strong_package`; the earlier `strong_some` remains its Prop-valued
specialization. This corrects an implementation restriction, not a newly
discovered limitation of MTT. Cooper's negative witness relation is a derived
semantic operation over the existing fixed type universe; negative and
function type constructors are still absent from `TTR.ty`.
