How to read the atlas

Four-point determination — a property of the theory, evidenced by its best formalization.

    Survey categories A–D map provisionally onto 1–4 and are shown tinted until code exists; a completed formalization replaces the prediction, and disagreements between the two are findings in their own right.

    Encoding artifact classes — what the encoding reveals about the theory.
    • (i) strict-positivity violation — its central relation is circular in a way type theory rejects
    • (ii) universe / type–value collapse — it identifies types with values
    • (iii) computational opacity — an operation that should compute becomes opaque (reals, exp/log)
    • (iv) missing native structure — needs machinery the substrate lacks (coercive subtyping, proof nets)
    • (v) decidability gap — assumes decidable equality or membership

    A theorem counts only if it ends in Qed and Print Assumptions lists nothing beyond signature parameters and axioms the source itself adopts. An Admitted is a finding (FALSE / NEEDS_ASSUMPTION / HARD), never a result.
