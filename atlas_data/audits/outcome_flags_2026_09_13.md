# Audit of source-outcome and related flags — 2026-09-13

Baseline: commit `887002bc4109fc425b4be41af380c25af52454e6`.
Scope: reporting rules and recorded provenance for all **230 survey entries**
and **78 file records**, including every previously inherited source outcome.
This is not a fresh reading of all 230 sources, an independent semantic review,
or a new compilation of the Coq corpus. Source-specific observations below are
grounded in the repository's existing source mappings and recorded limitations.

## Result

- The ten automatic “survey call disputed” badges are withdrawn. They were
  generated by comparing a survey prediction with the first eligible file's
  determination, without a source-level review or reconciliation of other files.
- All **29** inherited paper outcomes, including the **19 agreeing predictions**,
  are now source-review pending. The remaining 201 entries have no four-outcome
  candidates. There are **zero accepted source reviews** in the new registry.
- All file assessments remain accessible as candidates, with rationales, cited
  sources and mechanical/coverage cautions. Seven papers have linked candidates
  with different outcomes; no arbitrary first-file winner is chosen.
- Frozen P grades, all F levels, survey predictions, all 78 merged records,
  nine edges and the five-profile/27-target claim comparison are unchanged.
  Counts remain 1,318 theorem statements, 1,305 proved and 12 admissions.

Withholding an outcome is not a judgment that a theory cannot be formalized or
that its Coq proofs are invalid. In particular, substantial DisCoCat, DPL, PTQ,
InqB and RSA implementations remain substantial evidence. Their scope must be
reviewed against each particular source before making a paper-level claim.

The [machine-readable ledger](outcome_flags_2026_09_13.json) records before/after
states for all 230 entries and hashes of the frozen survey/grade inputs.
The [outcome policy](../OUTCOME_POLICY.md) defines the new acceptance gate.

## Related flags and wording

The audit also checked flag semantics outside the old paper badges:

- **File-review disputes:** the merge now requires literal `agrees: false`.
  Missing or unknown agreement is not a negative review. None of the 78 current
  merged records has a `.verify.json` review; mechanical `.mech.json` evidence
  exists separately and must not be mistaken for source review.
- **Source gaps:** 37 records have a nonempty `source_gap` value: 28 strings and
  nine objects. These are now labelled “Recorded source note,” not automatically
  “Gap found in the published source.” String values are actually displayed;
  some explicitly say “None.” Raw claims about source gaps remain attributed
  to the record, not independently confirmed by this audit.
- **Faithfulness/determination:** file pages identify these as recorded file
  assessments. The generated summary explicitly counts files, not paper outcomes,
  and includes the formerly omitted `faithful-with-corrections` table category.
- **Depth/assumptions:** triviality, vacuity, admissions and assumption flags are
  preserved. Signature parameters need not be logical premises; an intentional
  incompatibility theorem can have inconsistent premises. The rubric no longer
  falsely says depth-flagged theorems are automatically excluded from raw counts.
- **F5:** the existing edge/file-review rule and all levels are unchanged. The
  UI and README now clarify that pipeline progress is not source certification.
